CSS Dasar

📖 Apa itu CSS?

CSS (Cascading Style Sheets) adalah bahasa untuk menghias tampilan HTML. Kalau HTML adalah kerangka rumah, CSS adalah cat, wallpaper, dan dekorasinya.

🎨 3 Cara Menulis CSS

  • Inline — langsung di tag: <p style="color:red">
  • Internal — di dalam <style> pada <head>
  • External — file terpisah style.css ✨ (cara terbaik & paling rapi)

🧩 Struktur Selektor, Properti, Nilai

h1 { /* selektor: kita pilih elemen h1 */ color: #FF5556; /* properti: warna teks */ font-size: 32px; /* properti: ukuran huruf */ text-align: center; /* properti: posisi teks */ }

🌈 Properti CSS yang Sering Dipakai

PropertiFungsi
colorWarna teks
background-colorWarna latar
font-size / font-familyUkuran & jenis huruf
margin / paddingJarak luar / dalam elemen
border-radiusSudut membulat
display: flexLayout flexbox
