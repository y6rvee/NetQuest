Pemrograman Web Lanjut

📖 Responsive Web Design

Website modern harus tampil rapi di semua ukuran layar: HP, tablet, maupun laptop. Caranya dengan Media Query dan Flexbox/Grid.

📱 Media Query — Ubah Tampilan Sesuai Lebar Layar

/* Layar kecil (HP): tampil 1 kolom */ .container { display: grid; grid-template-columns: 1fr; } /* Layar lebar (laptop): tampil 3 kolom */ @media (min-width: 768px) { .container { grid-template-columns: 1fr 1fr 1fr; } }
