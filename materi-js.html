JavaScript

📖 Apa itu JavaScript?

JavaScript adalah bahasa pemrograman yang membuat halaman web hidup dan interaktif. Tombol yang bisa diklik, game, kuis di NetQuest ini — semuanya dibuat dengan JavaScript!

📦 Variabel — Tempat Menyimpan Data

// 3 cara membuat variabel let nama = "Budi"; // bisa diubah const pi = 3.14; // tetap / tidak bisa diubah var umur = 17; // cara lama alert("Halo, " + nama + "!"); // menampilkan popup

🔀 Percabangan (if-else)

let nilai = 85; if (nilai >= 75) { console.log("Lulus! 🎉"); } else { console.log("Belum lulus, semangat!"); }

🔁 Perulangan (for)

for (let i = 1; i <= 5; i++) { console.log("Perulangan ke-" + i); }

Buka template JavaScript di Lab Koding, ubah nilai variabel nilai menjadi di bawah 75, jalankan, dan lihat hasilnya di kotak dialog!
