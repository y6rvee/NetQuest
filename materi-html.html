HTML Dasar

📖 Apa itu HTML?

HTML (HyperText Markup Language) adalah bahasa markup untuk membuat struktur halaman web. Bayangkan HTML seperti kerangka rumah — menentukan bagian-bagian seperti pintu, jendela, dan dinding sebelum dihias.

🏗️ Struktur Dasar Dokumen HTML

<!-- Kerangka dasar setiap halaman web --> <!DOCTYPE html> <html> <head> <title>Halaman Pertamaku</title> </head> <body> <h1>Halo Dunia!</h1> <p>Belajar HTML itu menyenangkan.</p> </body> </html>

🧩 Tag-Tag Penting yang Wajib Diketahui

TagFungsiContoh
<h1>–<h6>Judul / heading<h1>Judul Besar</h1>
<p>Paragraf teks<p>Isi paragraf...</p>
<a>Tautan / link<a href="web.html">Klik</a>
<img>Menampilkan gambar<img src="foto.png">
<ul> / <ol>Daftar poin / bernomor<li>item</li>
<div>Wadah / container<div class="kotak"></div>

💡 Tips: tag selalu berpasangan — ada tag pembuka <p> dan penutup </p>. Ada pula tag tanpa penutup seperti <img> dan <br>.
